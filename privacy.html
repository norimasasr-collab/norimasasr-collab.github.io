プライバシーポリシー

最終更新日：2026年9月15日

sekaibiyori-upload（以下「本ツール」）は、運営者本人が自身のYouTubeチャンネルを管理するために使用する 個人用ツールです。本ツールは第三者に提供しておらず、運営者以外のユーザーのデータを取得しません。

1. 取得する情報

本ツールは、Google アカウントによる認可（OAuth 2.0）を通じて、以下の範囲にアクセスします。

  • YouTube 動画のアップロード権限（youtube.upload）：運営者本人のチャンネルへ動画を投稿するため
  • YouTube アカウント情報の読み取り（youtube.readonly）：投稿先が意図したチャンネルであるかを照合するため

氏名・住所・電話番号・決済情報などの個人情報は取得しません。

2. 情報の保存

認可によって発行されたアクセストークンおよびリフレッシュトークンは、 運営者本人のパソコン内にのみ保存されます。外部のサーバーへ送信・保管することはありません。

3. 情報の利用目的

取得した権限は、運営者本人のチャンネルへ動画をアップロードし、 その動画のタイトル・説明・タグ・サムネイルを設定する目的にのみ使用します。 これ以外の目的には使用しません。

4. 第三者への提供

取得した情報を第三者へ提供・販売・共有することは一切ありません。 広告配信やアクセス解析のための第三者サービスも利用していません。

5. Google ユーザーデータの取り扱い

本ツールによる Google API から受け取った情報の使用および他アプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （限定的使用の要件を含む）に準拠します。

6. アクセス権の取り消し

付与した権限は、Google アカウントの「サードパーティによるアクセス」 からいつでも取り消せます。取り消した時点で本ツールはチャンネルへアクセスできなくなります。

8. 改定

本ポリシーの内容は必要に応じて改定することがあります。改定した場合は本ページに掲載します。
